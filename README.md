# 1º Desafio

 > ℹ️ **NOTE:** Esta é o primeiro desafio que faz parte do treinamento *Crie Agentes Autônomos com IA*. [I2A2](https://sites.google.com/i2a2.academy/agentes-autonomos-com-ia-gen/in%C3%ADcio?authuser=0)

Para esta primeiro desafio foram elaborados 3 atividades que consiste em:
- Atividade 1 - Analisar textos em outra língua
- Atividade 2: Qual é o equipamento defeituoso?
- Atividade 3: Criar uma nova versão da história “Chapeuzinho Vermelho”

## 💻 Tecnologias utilizadas para realizar as atividades

- [ChatGPT](https://chat.openai.com/)
- [DeepSeek](https://chat.deepseek.com/)
- [Qwen](https://chat.qwen.ai/)
- [Bing Image Creator](https://www.bing.com/images/create)
- [Copilot](https://copilot.microsoft.com/chats/pPr3hxfqnsmfui4hg1tEL)


## 🛠️ Instruções de execução

As instruções para a realização das atividades do desafio 1 foram explicadas na live no youtube, contudo foi ainda disponibilizado aos alunos demais orientações sobre as tarefas no sitio da [I2A2](https://sites.google.com/i2a2.academy/agentes-autonomos-com-ia-gen/desafio-1?authuser=0)
